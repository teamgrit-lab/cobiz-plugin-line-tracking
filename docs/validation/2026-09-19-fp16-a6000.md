# Swin-L FP32/FP16 A6000 Validation

## Input and environment

- Input: `/home/gritandgrind/Downloads/20260911_025838_teamgrit_rosbag_0.mcap`
- Topic: `/a2/front_camera/res_720p/image_raw`
- Source duration: 73.502 seconds; 1,470 camera frames at approximately 20 Hz
- Samples: offsets 0, 25, and 50 seconds; 20 consecutive frames per offset
- GPU: NVIDIA RTX A6000 48 GB
- Model revision: `4772b6bf101d91f2534c106dc524d906aeb3c68a`
- Input/evaluation: `224x384` model input, `360x640` score map
- Seed: 0 in both independent processes

Another Python process occupied approximately 24,976 MiB during this run.
PyTorch's per-process allocated-memory counters remain useful, but wall-clock
throughput is intentionally excluded from the verdict.

Transformers 5.16.1 reported the same missing Swin final LayerNorm weight/bias
and unexpected relative-position buffers in both processes. Fixed seeding was
applied before each model load so independently initialized values do not add an
uncontrolled FP32/FP16 difference.

## Reproduction

Run FP32 and FP16 captures in separate processes, then compare them:

```bash
python tools/validate_swin_l_self_quality.py \
  --input /home/gritandgrind/Downloads/20260911_025838_teamgrit_rosbag_0.mcap \
  --topic /a2/front_camera/res_720p/image_raw \
  --output-dir rosbag-results/fp16-validation \
  --label fp32 --profile swin-l-aspect-224x384 --device cuda \
  --offsets 0 25 50 --frames-per-segment 20 --repeat 1 --seed 0

python tools/validate_swin_l_self_quality.py \
  --input /home/gritandgrind/Downloads/20260911_025838_teamgrit_rosbag_0.mcap \
  --topic /a2/front_camera/res_720p/image_raw \
  --output-dir rosbag-results/fp16-validation \
  --label fp16 --profile swin-l-aspect-224x384-fp16 --device cuda \
  --offsets 0 25 50 --frames-per-segment 20 --repeat 1 --seed 0 \
  --reference-npz rosbag-results/fp16-validation/fp32-run1.npz

python tools/compare_swin_l_precision.py \
  --fp32-npz rosbag-results/fp16-validation/fp32-run1.npz \
  --fp16-npz rosbag-results/fp16-validation/fp16-run1.npz \
  --fp32-report rosbag-results/fp16-validation/fp32-report.json \
  --fp16-report rosbag-results/fp16-validation/fp16-report.json \
  --output rosbag-results/fp16-validation/comparison.json
```
